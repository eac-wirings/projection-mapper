Projection Mapper

  1. Connect the projector, set it to extend the desktop, and drag this browser window onto it. Press F for fullscreen.
  2. Set Projector resolution to the projector's native size (try Use this screen). Turn projector keystone off, then focus and zoom using 4 Grid. After this, don't touch the projector.
  3. In 1 Map, press B to light the house dimly. Click + House template, or press N for a new shape. Select a shape, then click its corners on the real house. Use the arrow keys for pixel-exact nudges.
  4. Check alignment with 2 Masks and 3 Test. Set each shape's role: Show (content plays here), Block (forced black, e.g. windows) or — (guide only).
  5. Export the SVG/PNG guides and make your content at exactly the projector resolution, using the guide as a reference layer.
  6. Add your videos and images to the Playlist and press Play. Items rotate with crossfades. If the projector moved, fix it with 5 Pin without remapping.

Your map autosaves in this browser. Use Save map .json to keep a backup.
